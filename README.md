## 实习经历

### 广州途道信息科技有限公司 · 嵌入式软件实习生

`2026.02 — 2026.06` · 智能硬件 / 机器人设备端

- 实现协议驱动的设备显示能力，支持二维码、静态图片、动图叠加和状态栏等显示模式，并处理协议资源名与设备资源不一致的问题。
- 通过串口日志和测试帧定位显示页面切换、资源生命周期与硬件执行异常，沉淀可复现步骤、验证记录和排障文档，提升跨端联调效率。
